# UCI Java Midterm Study Guide

Based on the uploaded midterm, focus on five areas:

1. Java Fundamentals: valid primitive/data types, Boolean defaults, `new`, Scanner input, prefix increment, package/default access, `break`, `final`, 32-bit `int`, do-while, arrays, `static`, JVM, and String `==` behavior.
2. Java Swing: JFrame, JLabel, JButton, JTextField, `add()`, GridLayout, ActionListener, `setVisible(true)`, `addActionListener()`, and close operations.
3. Inheritance & Polymorphism: `extends`, method overriding, `super()`, code reuse, parent constructors, polymorphism.
4. MariaDB JDBC: MariaDB JDBC driver, `jdbc:mariadb://host:port/db`, `DriverManager.getConnection`, Connection/Statement/ResultSet, and closing connections.
5. Exception Control: try/catch/finally, ArithmeticException, `throws`, uncaught exceptions, `getMessage()`, `printStackTrace()`.

Recommended review sequence: read concept -> run matching Java example -> answer practice questions without notes -> check instructor key.
