# Instructor Guidance

Recommended demonstration sequence:

1. Verify MariaDB in Terminal.
2. Show `library_db` and `books`.
3. Show Connector/J on Eclipse Classpath.
4. Run `DatabaseConnectionTest`.
5. Explain `DatabaseManager`.
6. Demonstrate `LibraryService.search()`.
7. Demonstrate Add / Remove.
8. Demonstrate Checkout / Return.
9. Run `Main`.
10. Add a book, exit, restart, and prove persistence.

Keep student working projects on local disk. Google Drive should be used for
distribution/backups/submissions rather than as the live Eclipse workspace.
