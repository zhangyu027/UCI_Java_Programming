INSTRUCTOR-ONLY REFERENCE SOLUTION
==================================
Import with Eclipse > File > Import > General > Existing Projects into Workspace.

Before database execution:
1. Install/configure MariaDB.
2. Run sql/library_setup.sql.
3. Add MariaDB Connector/J to the project's Classpath.
4. Set UCI_LIBRARY_DB_URL, UCI_DB_USER, UCI_DB_PASSWORD (recommended).
5. Run instructor.finalproject.library.Main.

Do not distribute this folder to students; it contains the complete reference implementation.
