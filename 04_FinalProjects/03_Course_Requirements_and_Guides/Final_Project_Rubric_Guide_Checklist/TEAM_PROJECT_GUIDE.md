# Team Project Guide

The Canvas team-management assignment expects defined roles/responsibilities, tasks, milestones, communication, integration/testing, and documentation.

## Suggested 3-person split
**Team Lead / Integration**
- Requirements, repo structure, menu integration, final testing, presentation coordination.

**Developer 1 / Database**
- MariaDB schema, JDBC connection, add/remove/search operations, database tests.

**Developer 2 / Transactions & UI**
- Checkout/return logic, input validation, text UI, error handling, test scenarios.

For a 2-person team, combine the Team Lead responsibilities with one developer role.

## Milestones
1. Sprint 1 — schema + class design + pseudocode.
2. Sprint 2 — CRUD/search implementation.
3. Sprint 3 — checkout/return + UI + validation.
4. Finalization — integrated testing, bug fixes, documentation, ZIP, PowerPoint.

## Communication evidence
Record weekly meeting date, attendees, decisions, blockers, next tasks, and owner. Use an agreed channel such as Teams/Slack/email/GitHub.
