# Final Project Rubric / Submission Checklist

## Application
- [ ] Java application is functional and integrated.
- [ ] Library requirements are demonstrated.
- [ ] MariaDB persistence works.
- [ ] Input validation and error messages are appropriate.
- [ ] Code is readable and organized.

## Presentation
- [ ] PowerPoint identifies all group members.
- [ ] Presentation demonstrates the application and explains design/algorithm choices.
- [ ] Every group member participates.
- [ ] Team is prepared for the Canvas-specified presentation length.

## Submission
- [ ] Zipped Java application.
- [ ] PowerPoint.
- [ ] Team management documentation as assigned.
- [ ] Pseudocode submission as assigned.

The supplied Canvas rubric is authoritative for grading; use this checklist as a preparation aid.
