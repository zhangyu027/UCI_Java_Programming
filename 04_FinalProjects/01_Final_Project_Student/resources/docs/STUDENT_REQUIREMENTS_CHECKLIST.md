# Student Final Project Requirements Checklist

Use the Canvas materials supplied by the instructor as the authoritative assignment source.

## Required application behavior
- [ ] MariaDB connection works.
- [ ] Book table stores ID, title, author, available copies.
- [ ] Add book with input validation.
- [ ] Remove book by ID with validation.
- [ ] Search books by title or author.
- [ ] Check out a book by decreasing available copies.
- [ ] Return a book by increasing available copies.
- [ ] Text-based user interface provides clear prompts/messages.
- [ ] Persistent data survives program restart.
- [ ] SQL uses PreparedStatement for user-provided values.
- [ ] JDBC resources are closed with try-with-resources.

## Team/submission
- [ ] Team plan completed.
- [ ] Pseudocode completed by assigned responsibilities.
- [ ] Application ZIP prepared.
- [ ] PowerPoint prepared.
- [ ] All group members prepared to present.
