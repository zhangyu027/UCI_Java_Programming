# Suggested Teaching Sequence

1. Explain database / JDBC architecture.
2. Verify MariaDB from Terminal.
3. Run DatabaseConnectionTest.
4. Teach SELECT and ResultSet.
5. Teach INSERT with PreparedStatement.
6. Teach UPDATE.
7. Teach DELETE.
8. Connect each operation to Swing buttons.
9. Discuss input validation and exceptions.
10. Verify persistence directly in MariaDB.
