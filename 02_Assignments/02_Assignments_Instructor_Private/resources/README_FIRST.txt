UCI Java Programming FA2026 - Teacher Eclipse Project
=====================================================
This is the instructor-only ready-to-import Eclipse project rebuilt from the actual Canvas assignment, in-class practice, and final-project materials supplied for the course.

IMPORT
1. Unzip this folder.
2. Eclipse > File > Import > General > Existing Projects into Workspace.
3. Select this folder and Finish.
4. JDK/JRE target is JavaSE-21. If Eclipse asks, map it to any installed Java 21 JDK.

WHAT IS INCLUDED
- src/instructor/assignments : complete reference solutions for the actual homework themes.
- src/instructor/inclass     : complete reference solutions for the in-class practice themes.
- src/instructor/finalproject: complete MariaDB Library Management System reference solution.
- docs/expected_outputs      : sample outputs / expected behavior.
- docs/instructor_notes      : teaching notes, grading guidance, and MariaDB setup.
- sql                        : database setup scripts.
- data                       : sample files used by file-I/O exercises.

IMPORTANT
Database programs compile with the standard JDK but require the MariaDB JDBC driver at runtime. Add mariadb-java-client.jar to the Eclipse Build Path before running DB examples. Do not distribute this teacher project to students; it contains answer keys.
